# RUCLO - Project Brief

**Launch Date:** June 6, 2026 (15-week timeline)  
**Current Week:** Week 3 - Photo Upload Onboarding UI  
**Status:** In Development

## What We're Building

India's first fit-first fashion platform. Users upload 3 photos + height → AI estimates measurements → Match to hand-measured garments → Show swipeable styled outfits with "Styled for you" badges.

## Core Value Proposition

- **Photo-based measurement onboarding** - Upload 3 photos (front, side, face) + height
- **AI measurement estimation** - Estimate body measurements from photos
- **Fit matching algorithm** - Match users to hand-measured garments
- **Virtual try-on** - "Try This On Me" generates AI image of user wearing outfit
- **Educational overlays** - "Why this will fit you?" explains fit reasoning

## Key Goals

| Goal | Target |
|------|--------|
| Return rate | <10% (vs industry 40%) |
| Inventory sell-through | 75% within 3 months |
| User engagement | 4+ min session time |
| Photo upload completion | >80% of signups |

## Platform Structure

1. **Stylist** (main homepage) - Swipeable styled looks with fit badges
2. **Editorial** - Magazine-style content
3. **Browse** - Search/filter with "My fit only" toggle
4. **Product Pages** - Individual items with fit predictions
5. **Account** - View/edit measurements, Style DNA

## Success Metrics

- <10% return rate proves fit matching works
- 75% sell-through proves demand
- Users willing to upload photos for better fit
- Educational overlays create lasting behavior change

## Current Focus

Building the complete onboarding flow (5 screens):
1. Welcome → 2. Instructions → 3. Upload → 4. Processing → 5. Reveal
